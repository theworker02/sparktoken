# sparktoken

Spark URLs and token query parts with stable normalization.

**Site:** https://theworker02.github.io/sparktoken/

## Install / run

```bash
git clone https://github.com/theworker02/sparktoken.git
cd sparktoken
node src/cli.js
node --test
```
